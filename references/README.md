# Grounding references

Aletheia is grounded in these five works:

1. Patrick Blackburn, Maarten de Rijke, and Yde Venema, *Modal Logic*, Cambridge Tracts in Theoretical Computer Science 53, Cambridge University Press, 2001.
2. Valentin Goranko, *Logic as a Tool: A Guide to Formal Logical Reasoning*, Wiley, 2016.
3. Wolfgang Schwarz, *Logic 2: Modal Logic*, 2024 lecture notes, licensed under Creative Commons BY-NC-SA 4.0, [github.com/wo/logic2](https://github.com/wo/logic2).
4. Stephen Muggleton and Luc De Raedt, “Inductive Logic Programming: Theory and Methods”, *Journal of Logic Programming* 19–20 (1994), 629–679.
5. Filip Železný and Nada Lavrač (eds), *Inductive Logic Programming: 18th International Conference, ILP 2008*, Lecture Notes in Artificial Intelligence 5194, Springer, 2008.

The source materials are not redistributed with this package. Readers can consult
the publishers, Cambridge University Press, Wiley, Elsevier, Springer, and the
original authors’ repository for the works above.
