# Aletheia package workspace

This directory contains the focused packages in the Aletheia monorepo:

- [`AletheiaCore`](AletheiaCore/) — syntax, semantics, relations, and theory;
- [`AletheiaData`](AletheiaData/) — model families and scalar data;
- [`AletheiaLearn`](AletheiaLearn/) — inductive logic programming foundations;
- [`AletheiaSole`](AletheiaSole/) — SoleLogics compatibility adapters;
- [`AletheiaCircuits`](AletheiaCircuits/) — finite distribution-semantics circuits;
- [`AletheiaGraphs`](AletheiaGraphs/) — typed knowledge graphs and relational frame adapters.

The repository root contains the umbrella [`Aletheia`](../) package. Start with
its [README](../README.md) or the [documentation](https://eduardstan.github.io/Aletheia.jl/).
